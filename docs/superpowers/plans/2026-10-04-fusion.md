# Fusion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend big-little with a lead plus sidekick pairing, a generic sidekick agent, a brief guard, and a `/fusion` command.

**Architecture:** Setup resolves options plus env once, then registers an agent transform for the in-plugin sidekick, a tool guard that throws brief text, and a `/fusion` command that shows and sets the pairing per session. Effort travels as the variant suffix on the lead model switch, so no session context hook is needed.

**Tech Stack:** TypeScript ES2022 NodeNext, `@opencode/plugin@^2.0.16`, `node:test` plus `tsc`.

**Spec:** `docs/superpowers/specs/2026-10-04-fusion-design.md`

## Global Constraints

- OpenCode v2 plugin API only. Entrypoint stays `Plugin.define({ id: "big-little", setup(ctx) })`.
- Transforms stay synchronous, cheap, replayable. Option and model data resolves before callbacks.
- `session context` hooks expose model as readonly, so no per-dispatch model swap in v1.
- `tool execute.before` can only mutate input or throw. Routing is advisory brief text.
- `switchModel` affects later turns only.
- No new dependencies unless the spec names them. None named.
- Keep `bulk-reader` and `code-writer` ids, descriptions, permissions, behavior unchanged.
- No `fastMode`. No stats in v1. No new dependencies.

## Review Focus

- Relative path with no session dir fails open and never blocks.
- Piped shell (`cat big | head -20`) passes while bare `cat big` over threshold blocks.
- Bad `provider/model` ref or unknown effort level in options or `/fusion` args leaves the stored pairing unchanged and names the expected form.
- `switchModel` failure leaves the pairing unchanged and reports error text.
- Effort without a lead change only updates the stored effort shown by `/fusion` show; it never touches other options.

### Task 3: Setup wiring for sidekick plus /fusion plus effort-as-variant (session-only)

**Files:**
- Modify: `src/index.ts`
- Test: `test/plugin.test.ts`

**Interfaces:**
- Consumes: `buildBulkReaderInfo`, `buildCodeWriterInfo`, `buildSidekickInfo`, `resolveFusionModels`, `resolveEffort` from Task 1, `handleV2ToolBefore` from Task 2.
- Produces: `parseFusionArgs(text: string) -> { leadModel?: string; sidekickModel?: string; effort?: string }`, `buildLeadModelRef(leadModel: string, effort?: string) -> { providerID: string; id: string; variant?: string }`, command `{ name: "fusion", description: string, execute: (input: CommandInvocation) -> Promise<void> }`. Setup closure holds `{ leadModel?: string; sidekickModel?: string; effort?: string; minLines: number; weak: boolean }`. Lead changes apply per session only via `ctx.session.switchModel({ sessionID, model })`; no global model default change. Effort travels as the variant suffix on the lead ref. `CommandInvocation` is `{ sessionID, prompt, delivery }`; prompt text extraction plus `sessionID` threading are part of the command implementation.

- [ ] **Step 1: Write the failing test**

```ts
it("setup registers in-plugin sidekick without touching old agents", async () => {
  const updates: Array<{ id: string; info: any }> = [];
  const stubCtx: any = {
    options: { minLines: 350 },
    agent: { transform: async (cb: any) => { cb({ update: (id: string, fn: any) => { const d: any = {}; fn(d); updates.push({ id, info: d }); } }); return { dispose: async () => {} }; } },
    tool: { hook: async () => ({ dispose: async () => {} }) },
    command: { transform: async () => ({ dispose: async () => {} }) },
    session: { get: async () => ({}), switchModel: async () => {} },
  };
  await mod.setup(stubCtx);
  assert.deepEqual(updates.map((u) => u.id).sort(), ["bulk-reader", "code-writer", "sidekick"]);
});
it("fusion arg parser accepts key value pairs in any order", () => {
  assert.deepEqual(parseFusionArgs("sidekick opencode/mimo-v2.5-free effort low"), { sidekickModel: "opencode/mimo-v2.5-free", effort: "low" });
  assert.deepEqual(parseFusionArgs(""), {});
  assert.throws(() => parseFusionArgs("lead not-a-ref"));
  assert.throws(() => parseFusionArgs("effort bogus"));

it("lead ref carries effort as variant suffix", () => {
  assert.deepEqual(buildLeadModelRef("anthropic/claude-sonnet-4-5", "high"), { providerID: "anthropic", id: "claude-sonnet-4-5", variant: "high" });

it("switchModel failure leaves pairing unchanged", async () => {
  let cmdExecute: any = null;
  const prompts: string[] = [];
  const stubFail: any = {
    options: {},
    agent: { transform: async () => ({ dispose: async () => {} }) },
    tool: { hook: async () => ({ dispose: async () => {} }) },
    command: { transform: async (cb: any) => { cb({ add: (def: any) => { cmdExecute = def.execute; } }); return { dispose: async () => {} }; } },
    session: { get: async () => ({}), switchModel: async () => { throw new Error("nope"); }, prompt: async (input: any) => { prompts.push(String(input?.prompt ?? "")); } },
  };
  await mod.setup(stubFail);
  await assert.rejects(cmdExecute({ sessionID: "sess-1", prompt: "lead anthropic/claude-sonnet-4-5", delivery: "user" }));
  await cmdExecute({ sessionID: "sess-1", prompt: "", delivery: "user" });
  assert.ok(!prompts.join("\n").includes("claude-sonnet-4-5"));
});
```
